# VASX-launcher
VASX (Vekx Account Switcher X) — ультралегкий (1.5 МБ) лаунчер игр и менеджер переключения аккаунтов Steam в 1 клик для Windows с интерактивным 3D-фоном на Three.js. ||| VASX (Vekx Account Switcher X) — Ultra-lightweight (1.5 MB) Windows game launcher &amp; 1-click Steam account switcher featuring an interactive Three.js 3D particle background.
