### Основные возможности
- **Чтение библиотеки Steam напрямую с диска:** Мгновенный парсинг локальных манифестов `appmanifest_*.acf` без задержек и сторонних API.
- **Умное автопереключение аккаунтов:**
  - Автоматически определяет, какому аккаунту принадлежит игра (`LastOwner`).
  - Быстро переключает профиль Steam через реестр Windows без ввода паролей и 2FA и сразу запускает нужную игру.
- **Интерактивный 3D-фон на 100 000 частиц:**
  - Симуляция течения на основе Simplex Noise на кастомных шейдерах GLSL.
  - Реакция на движения курсора и гиперзвуковые ударные волны с замедлением времени (**time-dilation**) при нажатии кнопки «Играть».
  - Независимость физики от частоты кадров (плавно на 60Hz, 144Hz и 240Hz).
- **Минималистичный Glassmorphism интерфейс:**
  - Прозрачные парящие панели (`backdrop-filter: blur`), шрифт 'Play'.
  - Мгновенный поиск по играм и фильтрация по платформам.
